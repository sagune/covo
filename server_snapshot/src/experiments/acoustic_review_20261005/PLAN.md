# 原生 SenseVoice 对旧最佳 9B 修改的声学复核

用户授权“先试试”。范围为冻结预测后的离线判别诊断，不训练、不自动恢复文字、不宣称新系统 CER。

## 锁定条件

- 旧最佳联合实验 B/text 最终2162步的1334条预测，CER622/21102=2.9476%，热词469/599=78.2972%。不重生成、不挑检查点。
- 历史AISHELL contextual dev 全1334条，不是官方14326全dev，也不是新的heldout。
- SenseVoiceSmall原生预训练字符CTC输出层 + 现有相同512维编码缓存。没有新音节探针、连接器或MLP；原生输出层不是额外模块。
- true、zero、mismatch三组各1334条。zero=编码特征清零，不是重新编码静音。错配继承已有固定置换。
- 规范化NFKC、去空白和Unicode标点；不使用OpenCC。保持此前实际评分口径。

## 推理和诊断严格分开

仅根据输入top1与冻结9B输出的编辑对齐构建连续修改块。字符DP并列优先顺序对角、删除、插入。每个块构造“其他9B修改保持不变，仅此块换回输入”的完整句候选，以同一音频对比两个候选。不读取参考来选择块或定位音频。

主要分析等长替换且句子上下文无声调拼音不同的块，避免插删长度偏好影响结论。同音、插删和不支持字串也保留并单列。

主证据：原生字符CTC边缘总log-likelihood差，修改后减原片段候选。按符号描述偏向，不调阈值、不加热词分数。声学分数含字符/拼写先验，不声称纯发音置信度。

固定辅助证据：将原生单汉字token概率按字典无声调发音求和，再条件化于单汉字或blank，得到无参数音节后验后做配对CTC评分。字典来自原生词表，不来自dev参考；同音拼写不因此区分。音节聚合改变相邻同音字符的CTC重复折叠，故仅探索性辅助，不据dev表现改方法。

全部evidence输出封存哈希后，才读取参考诊断：单块换回输入使CER减少为有害修改，CER增加为有效修复，CER不变为中性。这些标签仅分析，不进入推理。统计有害修改识别、有效修复保留、正确输入子集、误差单位及按句聚类2000次bootstrap，种子917。对照真实与清零/错配，不能把偏向原文误认为听懂声音。

## 工作量和停止条件

3组×1334个CTC输出层前向，不加载9B、不重算音频编码。预期分钟级；实际以进度为准。启动前检查GPU任务并使用已有实验GPU锁。任何缓存/源哈希、ID、有限值错误停止并保留输出；不缩小dev、不删失败样本。无法打分的候选逐条记原因，覆盖率必须报告。

先验证判别是否有效，不运行9B二次复核，不产生“保护后CER”，不自动开启训练。

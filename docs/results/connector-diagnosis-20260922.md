# 与旧 Afull 连接器的比较和诊断

2026-09-23，只读核查现有训练输入、代码和预测，未启动新训练或推理。

## 历史前后结果

全部采用 1,334 条 contextual dev、21,102 参考字、599 指定热词 mentions，无保护恢复。服务器核对旧 `B_probe_true.predictions.jsonl` 与本次 MLP true：ID 顺序、归一化 reference、模型白名单输入证据完全一致。

| 模型/训练状态 | 真实音频＋文本 CER | 热词召回 | 原本正确的 883 句中被改错 |
|---|---:|---:|---:|
| 旧 Afull_3243 MLP，纯音频预训练后直接迁移 | 2.9049%（613 错误） | 79.13%（474） | 102 |
| 同一 MLP 初始化，再做 17,294 条纠错训练 | 3.3172%（700 错误） | 74.12%（444） | 147 |
| 新文本条件 Residual，17,294 条纠错训练 | 3.3362%（704 错误） | 75.79%（454） | 143 |

旧匹配提示词纯文本基线为 624 错误，本次为 625，存在 1 字跨运行差异；故不是完全同一次运行的严格控制实验。旧 Afull 本来仅比其文本基线少 11 字错误，其 CER 改善区间覆盖零，不能把旧结果当作已经证实成功的方法。新 Residual 与 MLP 预训练历史不同，二者仅 4 字错误差距也不能证明某结构更优。

## 直接观察

1. 相同旧 MLP 的额外纠错训练后，比旧直接迁移多 87 字错误、少 30 个热词命中；正确输入被误改的句数增加 45。46 句此前前端及旧 MLP 都完全正确、现在 MLP 改错（总量增幅 45 还包括其他句修复）。
2. 训练输入 17,294 句中 13,040 句有错、4,254 句正确，句错误率 75.40%；dev 1,334 句中 451 句有错、883 句正确，句错误率 33.81%。来自同一分片池的扩量仍继承该分布差异。
3. 新 Residual 正确/全零/错配 CER 为 3.336/3.317/3.350%，正确对全零/错配分别只改变 23/14 句归一化预测；没有观察到可靠的对应音频收益。
4. MLP 正确/全零/错配 CER 为 3.317/2.929/82.855%。旧 MLP 错配是 9.075%；继续训练后输出对音频干预更敏感，但正确音频仍差于纯文本和全零。

## 机制解释：有代码依据的假设，尚未做因果消融

- 训练目标只有正确音频＋文本条件下输出 reference JSON 的交叉熵。每条样本参与训练，但错误样本比例很高；没有额外的“相对纯文本不退化”目标，也没有正确/错配音频的训练约束。它可能学到更强的修改倾向或文本侧捷径，而非可靠的声学纠错。不能仅以训练 loss 或上述相关性确诊过拟合。
- Residual 以 top1 文本作 query，自注意力后读取声学 K/V，再经 LayerNorm 和投影把 delta 加回 top1 的每个 token。训练时只用 true 音频；零初始化只保证初始等于文本基线，不保证训练后仍少改或不误改。
- 零声学帧也会经过带偏置的投影和位置编码，因此仍可能产生非零残差；与错配音频接近的行为共同提示它可能学到对具体语音内容依赖很弱的文本嵌入调整。没有测量注意力/残差大小，不能宣称已经确认固定偏置或完全忽略音频。
- 旧 MLP 有纯音频转写预训练，新 Residual 没有。MLP 能显著响应音频，但它过去的纯音频转写 CER 是 11.923%，明显不及 CBSense 输入的 3.810%。音频分支影响增强不等于把更可靠的证据引入纠错；“在冲突时覆盖更好的文本证据”是值得验证的解释，不能凭错配 CER 断言模型就在转写错配音频。

## 实际错误例子

`BAC009S0727W0341`：参考、前端、旧 MLP 均为“这是王惠部长和记者说的最多的一句话”；继续训练的 MLP 改为“王会”，新 Residual 改为“王慧”。另一个包含同一名字的 `BAC009S0727W0351` 重复出现相同改动。

`BAC009S0728W0182`：参考、前端、旧 MLP 中的“爱屋吉屋”，两套新训练结果均改为“爱屋急屋”。

这些例子是基于既有参考的诊断，未听音复核。它们也说明同音字不能仅凭声学内容确定：声学一致不等于字形正确，输入文本和热词提供的字形信息仍然重要。

研究判断：共同训练目标和分布问题应优先检查。新 Residual 的音频利用弱与 MLP 的音频影响过强是两种不同表现；增加相同分片训练量或把耦合强度继续增大，尚无结果支持其必然改善。

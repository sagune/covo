# 全部修改块的精确候选上限与CER约束召回诊断

日期：2026-10-07。用户授权扩大范围的oracle可行性诊断。已完成完整1334条计算和第二实现核验，没有训练、模型推理、占用服务器GPU、改变任何现有实验结果或加入第三种候选。

## 结论

只将复核范围从字典异音修改扩大到输入与初稿的全部修改，候选上限就由 **CER2.6016% / 召回81.8030%** 改善到 **CER1.8624% / 召回92.8214%**。最低CER和最高召回可由同一组选择同时达到。

在字符错误数不高于当前seed917/918/919的588/597/590个、旧初稿622个，以及当前均值对应的保守整数预算591个的条件下，最高召回全部仍为556/599=92.8214%，所选输出都只有393个错误。因此不是仅恢复全部CBSense输入、以CER3.81%换召回90.15%的伪收益。

最重要的可行性发现：**新增的同音替换覆盖贡献了几乎全部新增热词命中空间**。原190块加上368个同音替换（合计558块），就能同时达到CER1.9572%、召回92.6544%；进一步加入其他类型，只再增加1个mention、减少20个错误。当前核心障碍不仅是声学判决不准，还包括将同音实体改写排除在复核范围之外。

这些是使用参考选择的理论上限，不是模型取得的结果。普通声学分数也无法直接区分同音汉字；全类型实际复核仍需要上下文、热词与候选证据，不能声称更多声学训练自然能逼近oracle。

## 严格的候选边界

新增路由函数只接收样本ID、CBSense输入和冻结旧9B初稿；先规范化，再使用原输入/输出对齐规则提取所有非匹配块。没有使用参考、错误标签、热词命中标签或“已知错误位置”来创建候选。

每块仍只有两个选择：保持初稿片段，或恢复对应输入片段。允许空片段来表示插入/删除，也允许长度改变。没有添加N-best、词典或参考中的第三种文字。全部恢复可重建规范化CBSense输入，全部保持可重建旧初稿；每句逐项核验。

路由清单reference_free_all_edit_manifest.jsonl在oracle计分前封存。该清单不含参考、音频真假标签或错误诊断。既有posthoc_cases中的类型只用于分类说明和范围投影诊断，路由不读取其参考/diagnosis来决定候选。

共604块覆盖474句：368同音替换、190异音替换、31已知发音的插入删除/混合块、15发音未知块。按句块数：860句0块、363句1块、96句2块、12句3块、2句4块、1句5块。全部穷举2130个整句组合，最多一条32种组合；未按结果抽样、删难例或减少验证规模。

当前三个真实AUDIO/true输出也全部位于这个扩大后的候选池中。该空间包含旧方案的所有选择，是严格扩展而不是替换原基线。

## CER与召回能否兼顾

分别计算：最低CER（平局最高召回）、最高召回（平局最低CER）、旧初稿及各实际seed预算下的最高召回，以及均值预算floor((588+597+590)/3)=591下的最高召回。七个目标均得到393错误/556命中。

语料级精确Pareto前沿只有(393,556)一个点。第二实现保留每一个精确错误预算下的最大命中数、不使用原Pareto剪枝，重新验证了这一结果；另外逐句最少错误之和393、逐句最高命中之和556均一致。

不能把这种参考已知情况下的共存称为模型的CER非劣保证，更不能用oracle决定阈值、检查点、训练标签或推理路由。

## 剩余错误与修复情况

全部604块oracle相对旧初稿：173句CER改善、0句恶化、1161句不变，共减少229个错误，不新增错误。S/D/I由旧548/54/20变为334/46/13。原输入正确的883句在oracle下全部恢复正确，没有改坏。

热词：旧初稿丢掉87个前端已命中mention、增加16个命中；全类型oracle恢复这87个丢失mention并保留16个新增，最终540+16=556。它仍漏43个mention，来自当前两个片段选择无法解决的部分，不应宣称热词问题全部解决。

最优组合恢复的块数按原类型为：同音114、异音55、插入删除/混合15、发音未知3；其余保持旧初稿。这个分解是参考辅助解释，不是推理时“某类型一律恢复”的规则。

原190到558范围新增65个命中、减少136个错误；558到604只新增1个命中、减少20个错误。不同修改组合可能相互影响，不能把每块独立误差简单求和当整句结果；本报告使用整句穷举计算所有范围。

## 对后续的建议（未实施）

扩大覆盖的可行性成立，暂不需要先扩展到第三候选来证明潜力。下一步可优先设计全替换/同音实体复核，让模型结合上下文、热词与N-best选择原词或修改词；保留异音声学证据，但不要要求声音确定同音汉字写法。插入删除及发音未知仍应保留在完整评估中，可用类型消融检验收益。

未自动训练、重新生成CBSense、改变旧提示/检查点/候选预测或启动第二阶段实验。若后续训练，需要新锁定协议、匹配控制和未参与方案迭代的heldout；当前结果是重复使用的历史1334 contextual dev，不是官方14326全dev或新测试结果。
